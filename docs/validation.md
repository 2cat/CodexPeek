## 已核验与尚未核验

旧版在实际 2560 × 1600 桌面、175% 缩放时，任务栏高 84 个物理像素；组件为 434 × 70，位于任务栏现有空间中。额度倒计时和空闲标题已检查实际显示。多任务／等待确认排版使用演示数据验证，未为了测试而制造真实审批操作。

本次新版在相同桌面上，入口为 560 × 70，位置为 `(14,1523)`，保留任务栏现有高度。空闲弹窗为 735 × 280；三任务面板为 735 × 766。无损原生截图用于 README，内容全部为演示数据。先尝试系统 Acrylic，再增加深色底层限制亮背景对次要文字的影响；确认系统圆角、细边框与背景透色，未将 API 返回成功当作视觉验收。

实际缩放下的操作和截图使用 `--review` 暴露窗口以便观察；日常快捷方式不带该参数，不增加 Alt-Tab 窗口。启动快捷方式后已确认主程序和 Node 数据组件均从 `CodexPeek` 根目录运行。

内容摘要更新复用旧版 EXE：实机显示实时工具动作标题，回复摘要用明确的演示任务检查排版；流式回复文字改变时的视图更新由快照和增量事件回归测试验证。该次更新只涉及 JavaScript 数据组件，无需重新编译 C#。

全屏、任务栏自动隐藏、锁屏、Explorer 重启和显示器／缩放切换已有处理逻辑，但尚未逐项改变目标机器环境做完整实测。

GitHub Actions 的构建和布局测试只验证代码行为及构建链，不能替代目标机器的可见性、输入焦点、点击命中、进程退出和应用信任验收。
